## Project Overview

Today I learned the basics of graph theory and how to create and analyze graphs using NetworkX.

- Edges

- Directed graphs
- Weighted graphs
- Node degree
- Paths
- Shortest paths

## Mini-Project

I built a small social network using NetworkX.

The graph contains five people:

- Alice
- Bob
- Charlie
- David
- Emma

I added relationships between them and analyzed their connections using node degree and shortest paths.

For example, the shortest path from Alice to Emma is:

`Alice → Charlie → Emma`

## Technologies Used

- Python
- NetworkX
- Matplotlib
- Jupyter Notebook

## Key Learning

Graphs are useful for representing entities and the relationships between them. This forms an important foundation for knowledge graphs and Graph RAG.
