# Day 03 - System Prompts vs User Prompts

## What I learned
- A system prompt tells the model how to behave, including its role, tone, and style.
- A user prompt gives the model the task or question.
- Different system prompts can change how the same user request is answered.
- A system prompt does not give the model new knowledge or retrain it.

## What I built
An AI Persona Assistant using Gemini.

I gave Gemini the same user question with three different system personas:
1. Friendly Teacher
2. Technical Mentor
3. Casual Friend

## What I observed
The same user prompt produced different responses depending on the system prompt.

The responses differed in tone, vocabulary, level of technical detail, examples, and overall style.

## Conclusion
System prompts influence HOW the model responds, while user prompts specify WHAT the model should do.
